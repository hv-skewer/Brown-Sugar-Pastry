# Brown-Sugar-Pastry

一个用来分享「有用小知识」和收集「实用链接」的小仓库。

## 有用小知识

- 先做最小可行版本（MVP），再迭代优化。
- 记录问题时写清楚：现象、复现步骤、预期结果。
- 对外分享内容时，优先给出可直接使用的结论和示例。
- 复杂任务拆小：每次只处理一个明确目标。

## 链接收集区

## 使用方式

1. 在「有用小知识」里追加你验证过的经验。
2. 在「链接收集区」里添加标题清晰的链接。
3. 提交前简单检查：链接可访问、描述准确、避免重复。
